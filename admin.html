Sign in

GitHub Pages has no server, so there's no real username/password login. This uses a fine-grained GitHub personal access token scoped to just this one repository instead. It's held in sessionStorage only — never saved to disk, never sent anywhere except api.github.com — and disappears when you close the tab. Read README.md for how to create one and for the honest trade-offs of this approach versus a proper OAuth-based CMS.

Blog posts

New posts get the next id automatically (previous highest + 1). The date defaults to today — edit it if you're backdating a post. Selecting an image queues it for upload; it's actually committed to the repo when you click "Save changes" below.
